`FastAPI` is a modern, fast(high performance), web framework for building APIs with 
python based on standard python type hints

⏺ `Python type hints` are optional annotations that declare the expected types of variables, function parameters, and return values.

Type hints Key points:

- They are not enforced at runtime — Python remains dynamically typed
- Used by static analysis tools like mypy, pyright, and IDEs for error detection
- Introduced in Python 3.5 via https://peps.python.org/pep-0484/
- Python 3.10+ allows X | Y syntax instead of Union[X, Y]
- Python 3.9+ allows list[int] instead of List[int] (no import needed)
